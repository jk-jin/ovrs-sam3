# 对比实验：已确认方案与剩余实施工作

日期：2026-11-24。本轮仅调整论文、表格生成和结果选择规则；不修改模型或评测器，不运行训练和验证。

## 已确认方案

- 文献模型直接采用已登记的原报告值，不以当前公开仓库与历史论文完全一致作为纳入条件，不要求逐个复现。当前代码的线索保留为历史证据，不替代原报告，也不自动证明历史运行设置。
- 主表继续分为 Training on remote sensing segmentation data 和 Training-free；本模型属于前者。支持的训练方法统一选 DLRSD 来源，SkySense-O 单独注明 Sky-SA。
- UAVid 保留一列：本模型、两个本地 SAM3 基线与消融均采用合并 car 的七类协议；文献保留七／八类原值并以数值上标标记。未知口径用上标 u，不猜测类别数。不同协议不直接排名，不混算跨域均值。无须统一重跑旧八类模型。
- iSAID 拆为 15 cls. / IgnBG 与 16 cls. / BG 两个子列。IgnBG 完全忽略 GT 背景像素，再对十五个前景类求均值；BG 保留 GT 背景并纳入十六类均值。Full、Semantic-only、Semantic × Presence 均预留两个结果，复用每方法／种子的同一权重，不重复训练。
- 已有来源设置可辨的文献值放入相应子列；无法明确归类的原报告值跨两个子列显示一次并标 u，不依据训练组猜测、不重复填数。来源设置标记不宣称独立复现或所有细节相同。
- LoveDA 本模型采用七类含背景：原始 0 为 no-data，转为 255；原始 1..7 仅减 1 一次。历史值继续按来源引用；先前因仓库注册引起的疑问不再阻塞引用。
- ActiveSAM 使用 ProC-SAM3 reproduction 行，引用方法和实际取数来源；ROSE-SAM3 使用其论文报告值。无须先解决当前代码／README 的版本差异。
- GLoP-SAM3 使用 ROSE-SAM3 Table I 转引值，同时引用 GLoP 原论文和 ROSE 取数来源。尚未取得 GLoP 全文不阻塞透明转引，不称亲自复现或读过全文。
- GFMR、ConceptBank、PRS-Seg 不纳入比较且无正文引用；VLex-SAM3、ConceptSeg 继续排除。Zotero 导出库内未调用条目可保留，不会进入编译后的参考文献。

## 真正剩余的实施工作

1. 实现 iSAID BG 验证入口并固定背景预测方式、提示和阈值；保留原有 IgnBG 协议。不得根据 GT 决定背景预测，不得仅从十六类平均分扣除背景 IoU 来冒充 IgnBG。
2. 用同一权重完成两种 iSAID 评测，分别登记真实 eval_id、协议 ID、划分、种子与 checkpoint SHA-256。三个本地方法均填两列；标准结果中的 eval_dataset 仍为 isaid，以不同 eval_protocol_id 区分。
3. 主表 native_selection 使用 iSAID-15-IgnBG 和 iSAID-16-BG 两个选择键；其余数据集沿用原键。两键须使用相同种子／权重、不同协议 ID，不能共享一个结果冒充两种评测。
4. 完成主模型、两个基线、十个训练变体及效率测量，按既定来源与开发域规则填表。当前成绩与开销均为 --。
5. 方法正文、架构图及未使用的 RemoteCLIP 中间层提取清理属于后续任务，本轮未处理。消融配置尚未实现的部分见 manuscript_status.md。

不再把获取付费全文、外部版本确认或逐仓库复现列为本轮表格工作的前置条件。未知文献协议仍保留参考性质；用于具体提升幅度的对比必须具有一致且已明确的类别、划分和统计规则。
