\caption{RemoteCLIP-guided aggregation block. Each class prompt retains 64 template text vectors without averaging. Scaled cosine similarity with the final dense image features produces 64 score maps on a 36-by-36 grid. Score embedding projects these scores, directly fuses the dense image features, and encodes the concatenated score and fused paths into 256-channel guidance. L2 normalization before concatenation and convolutional normalization/activations are omitted for clarity. Guidance is prepared once per forward, outside the block, and reused across blocks while remaining differentiable through Q/K. Within each attention module, independently normalized features and semantic guidance are concatenated to form queries and keys (Q/K); values (V) come only from normalized conditional features. Feature-pyramid-network (FPN) guidance additionally enters intra-class Q/K. Intra-class inputs are resized before per-scale LN; shared multiscale attention is summarized by one path, and $\Sigma$ denotes weighted summation of aligned scale increments. The two plus signs are feature residual additions. LN denotes LayerNorm; final output LN follows the complete block stack. Convolution annotations show kernel size, repetition and channel changes. All vector bars and feature slices are schematic.}
\label{fig:aggregation}
