The symbol $\Sigma$ denotes summation with three learned scalar scale weights, and $+$ marks residual addition. Final LayerNorm (LN) follows the block stack. (c) SDF combines aggregated features with original conditional features and FPN72 before frozen decoding; high-resolution FPN features reach the decoder. Matching ports marked ``from (a)'' reuse the corresponding features. Snowflakes denote frozen SAM 3 modules and flames denote RemoteCLIP attention tuning. The gray strip shows training-only distillation using the same frozen decoder weights. Feature slices and prompt relations are schematic; image and response tiles are placeholders.}
